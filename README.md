
# Advanced Counter App (React + TypeScript + Tailwind CSS)

An interactive, feature-rich counter application built with React, TypeScript, and Tailwind CSS. Designed with a soft pastel UI, smooth interactions, and performant state management.

## ✨ Features

* **Core Counter Controls:** Increment, decrement, and custom step size support.
* **History Log:** Complete history of all counter values displayed in a fixed-height container with custom pastel scrollbars.
* **Debounced Auto-Save:** Persistent storage via `localStorage` with cleanup functions to eliminate race conditions.
* **Keyboard Navigation:** Native accessibility allowing users to adjust values using the `ArrowUp` and `ArrowDown` keys.
* **Reset Functionality:** Clears history, steps, and counter back to their initial state.

## 🛠️ Tech Stack

* **Frontend:** React (Hooks: `useState`, `useEffect`, `useRef`)
* **Language:** TypeScript
* **Styling:** Tailwind CSS
* **Build Tool:** Vite
